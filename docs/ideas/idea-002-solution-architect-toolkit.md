# IDEA-002 — Solution Architect Toolkit

*[Ideas Register index](README.md)*

## High-Level Description

Organize the Solution Architect's work the same way business requirements are organized: dedicated assistants and reviewers, practice guidance, commands, integrity scripts, and templates for architecture work such as assessments, decisions, and solution designs.
